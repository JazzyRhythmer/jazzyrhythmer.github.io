JR EMUL / GUIDE

Your first signal path.

Start with one slot, listen, then add a second character when the sound calls for it.

Choose a source

DEMO introduces the app. FILE imports your own audio; PLAY starts and stops file playback. INPUT processes live audio as soon as it is selected, subject to microphone permission and device routing. After the first successful import, the source controls focus on FILE / INPUT; DEMO remains available from the file options.

Choose, then combine

Select Slot A or B to edit its model, settings and MIX. The adjacent power controls each slot. Serial runs A then B; A/B switch selects one path. Double-tap a knob to restore its default. RESET A or RESET B targets that slot.

SP1200 uses RAW / WARM / DYNAMIC colors, with restrained movement in DYNAMIC. S950 exposes recording bandwidth; its playback filter has fixed resonance. ASR-10 offers its normal and low clock. 303VS offers COMP / NOISE / WOW.

Set the output

OUTPUT opens FILTER / COMP / LIMIT. Each stage starts off and has its own power. FILTER offers SP1200 / S950 / L24 / BASIC. BASIC provides LP / HP / BP. Master gain feeds the limiter. The limiter controls sample peaks and is not described as a certified true-peak limiter.

Keep a take

REC captures the final output including live changes. EXPORT processes the selected file using a snapshot of the settings. TAKES supports preview, naming, sharing and reuse as a file source. Offline export is a settings render, rather than a recreation of gestures performed later.

Use an AUv3 host

Insert JR EMUL as an audio effect. Route audio and control transport in the host. Standalone source and capture controls are hidden where the host owns those functions. Parameter automation and state recall are supported; actual routing and buffer behavior depend on the host.
