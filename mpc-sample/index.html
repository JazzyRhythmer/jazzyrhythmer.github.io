01 / FIND YOUR FLOW

Less blank canvas.
More starting points.

01

Generate. Then make it yours.

A four-track song group connects drums with melodic parts. Generate a starting point, mutate it while keeping sounds, or work on one track at a time. Repeatable seeds give an idea somewhere to return to.

02

A kit is not a single sound.

Start with a complete Rhythmer Kit, then replace individual pad sounds. Single instruments retain their own presets and sound controls. Different jobs, clearly separated.

03

Generate Acid. Rearrange breaks.

Acid has its own bassline generator. Break turns a loop into playable slices with dedicated pattern generation. Engine-specific pages follow the instrument you are working with.

ACID GENERATOR / DEDICATED BASSLINES

A new line.
Another way to move.

Generate, mutate and replay acid basslines with dedicated density, accent, slide, octave and seed controls. Shape the notes first, then perform the sound.

  • Three settings pages, with a seed for each track.
  • Slides, accents and sustained ties from the FM-1 generator lineage.
  • Optional Auto Mutate at a musical bar interval.
LEARN THE ACID GENERATOR ↗

BREAK MANIPULATOR / BRK PERF

Chop it.
Roll it. Play it.

Bring a loop, prepare sixteen slices, then get hands-on with rolls, A/B source switches, freeze, grain and stretch. Record those moves into the pattern.

  • Six performance pages built around the pads and three knobs.
  • Chops, repeat / up / down / shrink, Build, Stretch and Echo.
  • A/B sources, loop Variation / Drift and sequence-recorded commands.

Uses your own loops. No break recordings bundled. Source length is declared as 1–4 bars; cuts divide the complete loop equally.

What is inside Rhythmer Kit?

36 curated kits from Sophie, Elixir, Hortator, DRUM-X, K-WASUB drum mode, 6W6, 8W8, 9W9, CW-78 and TR-MPC. Kit-only sources are not additional standalone engine entries. The existing Sample Kit workflow remains a separate sampler option.

03 / FROM THE STUDIO

From FM-1 curiosity
to MPC Sample
possibilities.

I loved exploring open-source engines, building grooves and finding unexpected sounds with RHYTHMER OS on the FM-1. I wanted to bring that freedom and variety to the MPC Sample.

This project builds on Melodee. Much respect to its developers and contributors for sharing a foundation that gives the community room to experiment.

My work focuses on porting and optimizing additional engines for the hardware, integrating them with the existing foundation, and adding my own tools, UI refinements and workflow extensions. The original engine creators deserve the credit for their DSP, ideas and sound.

If you know the stock workflow, this may feel unfamiliar. Give it time, explore, and tell me what gets in the way. There is still plenty to refine.

In search of feel-good rhythms.

BEFORE YOU INSTALL

Back up. Check the version. Choose the right package.

This beta targets MPC Sample AC50 running firmware 1.3.0.12, with a microSD card. Other firmware versions are not supported by this launcher. Device installation, controls, listening, latency and recovery remain pending physical-device validation.

FIRST INSTALL / MOVING FROM 0.3

Full SD package

The SD ZIP includes the app, engines and kit data. Use it for your first installation and the move to 0.4. Back up your existing card before replacing files.

DOWNLOAD FULL SD ZIP ↗0.4.0-beta.1 · 70.6 MB · RECOMMENDED
COMPATIBLE RHYTHMER INSTALLS ONLY

Signed app update

The UPDATE ZIP replaces the running app. It does not install engines or kits. For the current catalogue change, use the full SD package. A Melodee update ZIP is not a RHYTHMER update.

DOWNLOAD APP UPDATE ↗0.4.0-beta.1 · 6.1 MB · APP ONLY
  1. Back up the whole card. Keep projects, samples, user presets, plug-in data and the previous autorun folder somewhere safe.
  2. Check the release and checksum. Match the package version to its installation notes and published SHA-256. Source archives are for developers; they are not SD installers.
  3. Extract the full SD ZIP to the card root. Keep autorun/ and Rhythmer/ at the top level; do not leave them inside an extra ZIP-name folder. Engines belong in Rhythmer/Plugins. Preserve the package’s Samples folder and supporting data.
  4. Keep signed startup files intact. Do not rename or edit files inside autorun. Insert the card with the device powered off, then start it. The stock application starts before the SD launcher hands over to RHYTHMER.
  5. Start small and save. Follow the first-pattern guide, check the output level and save a test project before a larger session. Use your own break audio; a built-in Amen loop is not included in the OS.
Updating an existing installation

Back up first. For the move from 0.3, use the full SD package. Existing top-level Plugins folders remain readable and are not automatically moved or deleted; matching engines in Rhythmer/Plugins take priority. Later compatible signed UPDATE ZIPs can be placed at the card root or transferred through the USB device page. Save before installing. The updater keeps the previous app in autorun/rhythmer.prev; follow the release-specific recovery notes if startup fails.

Returning to the stock application or an older beta

Use Exit → MPC APP to return to the stock application for that session. To stop SD startup, power off first and move the card’s autorun folder to your computer. To restore an older beta, restore its backed-up autorun and matching plug-in data together. Keep new 128-pattern / Freeze projects as separate copies; do not overwrite them in an older beta. Never remove the card while it is saving.

Versions, checksums and source files
