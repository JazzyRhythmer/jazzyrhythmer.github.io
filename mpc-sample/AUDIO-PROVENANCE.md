# Engine demo provenance

These are original short showcase performances rendered offline through the production Rhythmer sound host and the selected engine ports. They are not recordings from a physical MPC Sample. No substitute browser synthesizer is used.

Break Engine uses the production Melodee-derived sampler playing 16 equal slices of the requested Amen source. The Break source was later replaced with the requested Amen asset; see the revision note below.

The original DSP and factory patches remain the work of their respective authors. Rhythmer port/integration work and these short performance arrangements are separate contributions. Fixed gain and short edge fades were applied; no mastering effects or replacement instruments were added.

`demos.json` records source-render peak/RMS, gain, duration and delivered-file SHA-256. Audio is stereo 44.1 kHz, 16-bit PCM.
Engine screens use frames generated by the production UI renderer. They are symbolic source graphics, not measured waveforms or a physical-device recording. A first user click enables sound; subsequent scene selections and end-of-demo transitions play automatically.
Special-feature scenes use the corresponding representative instrument performance; they are not recordings of the firmware GEN algorithm executing.

## Updated production UI motion
All 20 engine motion sequences now use the current production performance_art renderer rather than the former web waveform overlay. 1,790 full-screen frames at 10fps were generated; render audit reported zero text issues. Demo WAV RMS drives the meter input; held activity is inferred from level and the reference pitch is fixed at MIDI 60. These previews therefore show the real rendering code and audio-level response, not an exact MIDI replay or hardware recording. Sprite atlases are synchronized to HTMLAudio currentTime. The engine detail panel uses the same rendered sequence as a visual preview.

## Demo revisions and original preset names
FM-106 now uses A11 Brass, from the pinned original FM-106 factory header. A11 Brass, A12 Brass Swell, A43 Brass Ensem and B31 Brass produced finite, non-silent output in the actual host. The selected original exposed parameter values were applied in a demo-only catalogue; the production port still omits the full vendor bank. No new factory bank or firmware patch has been installed by this website change.
S1Vave uses Default initial state; the invented Bright Lead patch was removed. Prophet uses INIT PROPHET with the requested cutoff edits, Hortator uses BOOM with longer decay, and MONO2K uses Super Saw with filter/modulation edits. These edits are not renamed as original factory presets and do not add presets to the product.
Break now uses the existing FM-1 Amen asset through the actual sampler, replacing the previous original DRUM-X source. This is a third-party recording, not an original recording by Jazzy Rhythmer; audio rights are separate from code licenses. This local preview is not a public release clearance.

## Percussion demo gate correction
Hortator BOOM, Elixir LXR Init / Kick and Sophie Kick were rendered again without the melodic 90 ms All Notes Off or the following step note-off. Natural one-shot tails now run until retrigger; the base pulse is 500 ms with an occasional syncopated hit. This is a demo MIDI performance fix, not a new preset or a firmware DSP change. First-hit raw RMS for Hortator: 0.09282 (100–200 ms), 0.07305 (200–400 ms); Elixir: 0.08175 and 0.01899 respectively.

## Full Rhythmer Kit performances and filter variation
Hortator, Elixir and Sophie now use the actual production Rhythmer Kit SoundRack with the original kit pad routing and a multi-pad kick/snare/hat/tom/cymbal MIDI pattern. Hortator retains the requested BOOM kick edit. Sophie uses demo-only per-pad metal, feedback, pitch sweep, crush, drive and ring-comb FX edits; this is labelled a performance edit and is not installed as a factory preset. S1Vave now selects original factory program 1, PTN 1-02, via the production VST2 Factory Program parameter. Acid uses the original ACID Bassline model with native cutoff and resonance automation over the performance. The latter two demos use the production VST2 plug-ins directly.

## Current demo revision: MD kit, Industrial, driven acid and short MONO2K ending
Hortator now uses original MD TRX and EFM model sounds, arranged in a temporary Rhythmer Kit demonstration (not a new factory kit): BDTRX kick, SDEFM snare, CPTRX clap, CHTRX/OHTRX hats, TMEFM tom, RSEFM rim and CYEFM cymbal. Elixir uses its original Industrial kit. Both delivered WAVs target RMS 0.19 through demo gain and smooth peak limiting, up from about 0.12.
Acid cutoff now sweeps 0.025–0.995 and resonance 0.66–0.98; envelope and accent are increased. Additional tanh distortion is offline demo processing, not a newly implemented firmware effect. MONO2K now receives explicit Note Off, has native release set to 0.08 and a 120 ms final fade ending at 8.05 s to clear residual effect tails. Original preset/model names are retained; no product presets were added. Delivered levels, processing and hashes are recorded in demos.json.

## Current demo revision: narrow crossing acid filter and full MD groove
Acid base cutoff now moves only from 0.22 to 0.43; resonance moves in the opposite direction from 0.88 to 0.64 on the same four-second cycle. Filter-envelope amount is reduced to 0.40 and accent to 0.70. Offline tanh saturation uses fixed 9x drive throughout, without distortion automation. This supersedes the previous wider cutoff sweep.
Hortator MD kit now uses independently instantiated source entries per pad in the demo-only catalogue, preserving each selected original MD model; the full kit pattern includes kick, backbeat snare, layered clap, closed/open hats, tom, rim and cymbal. These entries are not product presets. Non-kick velocities and percussion activity are increased.

## Current demo revision: four-on-the-floor and balance
Hortator kick now triggers on steps 1, 5, 9 and 13 in every sixteen-step bar (first event at sample zero). Kick native level is 0.50, tom level 0.27, tom velocity 62 with one fill per two bars. The first-bar cymbal is removed to expose the downbeat. The opening fade is shortened to 2 ms. Non-kick percussion remains in the full kit pattern. Acid cutoff is raised slightly to 0.25–0.48; inverse resonance 0.88–0.64, envelope/accent and fixed 9x saturation remain unchanged.

## Current MONO2K and Prophet selections
MONO2K uses the original FM Dynamic machine, filter base 0.04 and width 0.66 (reduced low-pass opening), keeping native release 0.08, explicit note-offs and the end fade. Prophet uses Forever Keys from the pinned original Sequential v1.03 record: all 57 exposed original native patch fields are applied in a demo-only catalogue, not a new preset or full bank installation. Original names are retained. Other engines were not re-rendered. Melodee attribution remains, with its bold styling removed.
