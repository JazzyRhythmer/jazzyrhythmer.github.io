Your first performance

Start with a source

Choose SOURCE on the main page. LOOP plays the built-in material, FILE uses imported audio, and INPUT uses a live input. They are alternative sources, not a mixer. Press PLAY for standalone playback; use your host for AUv3.

Choose, then enable

Tap a COLOR, TONE, LOOP or SPACE name to inspect it without changing its power. Hold the name to choose an effect type. The adjacent power key selects and toggles the category. New standalone sessions start with effect stages off.

Four knobs

The first main knob is VOLUME. The other three control the selected effect. Double-tap a knob to restore its default. The three effect controls change with the type; there is no separate global MIX knob.

XY pads, HOLD and RETURN

Touch the result

Each performance pad is an XY surface. The point you touch determines its two assigned values. Some screen sizes show 8 pads with bank controls; larger layouts show all 16.

Edit a pad

Open EDIT above the pads. Select a pad, then change its effect, values and X/Y parameter assignments. Pad settings persist; AUv3 projects restore their saved assignments.

Keep a gesture

HOLD keeps a performance active after release. RETURN releases the performance and returns to the underlying effect state. The iPad LCD XY surface links to the first two effect knobs.

Audio buses and output

BUS A / BUS B

Audio routing is separate from sequencer patterns. In split A/B routing, selecting a bus makes that bus the active effect path. In serial A → B routing, audio runs through both paths in order.

Signal path

Source → routed category effects → SEQ → EMUL → compressor → limiter → final output. EMUL and dynamics are optional. The master VOLUME and bypass controls remain available.

Sampler-inspired models

EMUL offers SP1200, S950, ASR-10, MPC60 and MPC3000 in that order. Select a model directly. SOFT CLIP and ANALOG shape the output character. Model controls and defaults vary; consult MODEL INFO for documented hardware behavior versus JR approximations. These are independent models, not manufacturer firmware.

SEQ: patterns, not audio buses

Enter directly

Tap SEQ beside EDIT above the pads. In compact page layouts, SEQ is beside SOUND / KNOBS / PADS. Opening the page does not enable the stage; use SEQ ON/OFF.

Edit and play independently

EDIT 1 and EDIT 2 choose the pattern you edit. PLAY 1, PLAY 2 or PLAY 1→2 chooses playback independently. These numbered patterns do not select BUS A/B. FOLLOW follows steps only while the chosen edit pattern is playing.

Shape and span

On SHAPE, select a step and draw its curve or choose a shape. Quick spans are 1, 2, 4, 8 and 16 grid steps. SPAN supports up to 64, bounded by the pattern. The four step pages show 1–16, 17–32, 33–48 and 49–64.

Timing and target

TIMING sets the rate, sync/free behavior, swing, smoothing, direction and pattern length. FX selects a filter, VOLUME, PAN, DRIVE or CRUSH and the applicable range controls. Patterns and curves remain when changing target.

Return without losing your place

Tab, edit step and copied shape survive page navigation in the current app/plugin instance. A fresh instance resets that editor navigation and clipboard. Saved pattern/audio values continue to use app or host state.

Import, record and export

Bring a track

Hold SOURCE for SETUP → INPUT. IMPORT AUDIO and FILE use the same Files picker. Supported formats include WAV, AIFF, CAF, MP3, M4A (AAC/ALAC) and FLAC. Long tracks are processed from disk; protect the original file and allow cloud files to finish downloading first.

Record the actual performance

In standalone, start playback, then open REC. AUDIO captures the final output, including your pad and knob moves. Hold REC to start or stop an audio take when available. Stop recording without stopping playback, then rename, preview or share the take. Imports and offline export are unavailable during a take.

Offline export is different

EXPORT WAV processes a file using a snapshot of the current settings. It does not recreate gestures played later. It adds a fixed two-second tail; use live recording when long echo/reverb tails or live gestures matter. WAV/RF64 output and progress/cancel support long files.

Screen + audio

Standalone REC also exposes screen/audio recording through system capture. System consent and device support are required. Leaving the app ends/finalizes the take; background input audio is a separate setting. In AUv3, record or render in the host.

Live input and AUv3

Input controls

SETUP → INPUT provides device/channel-pair selection, L / L+R / R, gain, meter, monitoring and background-audio preferences. Choose INPUT, check the physical route and gain, then explicitly enable monitoring. Use headphones to avoid feedback.

Use as an effect

Load JR FX as an AUv3 audio effect after the instrument or bus in a compatible host. Route audio through it and enable the desired stages. The host supplies audio, transport and automation. Save your host project to retain the effect state.

In a Koala workflow

JR FX processes incoming audio; it does not host Koala. Route Koala into JR FX in an AUv3 host, or export audio from Koala and import it into standalone JR FX. Available routing depends on the host and device.

Skins, support and credits

Modern first, JR after

Modern BK is the default for a fresh installation. The skin list shows Modern BK followed by JR XL, JR BK and JR BL. An explicitly saved skin remains selected. Skins change presentation, not the sound.

Know the model

SETUP → INFO contains QUICK GUIDE, MODEL INFO and open-source licenses. Hardware references document a design target; they do not establish bit-identical behavior, endorsement or measurements of your own unit.

Report a problem

Include app version/build, device/OS, standalone or host, audio route and steps to reproduce. Please do not send private recordings unless you intend to share them.
