Install 0.2.0.

Use the full SD ZIP to install RHYTHMER OS. It contains the app, plug-ins, kits and preset catalogue. Back up the entire card before installation.

  1. Save your music. Power off the Sample, remove the SD card and back up the entire card, including projects, samples, presets and the existing autorun folder.
  2. Check the device is MPC Sample AC50 running stock firmware 1.3.0.12. This release is not an FM-1 installer.
  3. Download the full SD ZIP and its SHA-256 file. On macOS, run shasum -a 256 RHYTHMER-OS-0.2.0-SD.zip and compare the result.
  4. Extract the ZIP. Copy its contents to the card root, keeping autorun/, Rhythmer/ and Samples/ at the top level. Copy all supplied app and plug-in files; preserve your own projects, presets and recordings.
  5. Eject the card safely, insert it and start the Sample. Follow the SD launcher. Check the version is 0.2.0 before creating your first project.
SD card/
├── autorun/
├── Rhythmer/
│   └── Plugins/
└── Samples/

Using Boot Thingy? These steps are for direct SD boot. Keep Boot Thingy’s launcher and follow its app installation instructions instead of replacing its autorun files.

Keep a way back.

To return to the stock app, power off, remove the card and move autorun/ off the card. Keep your projects, samples and recordings backed up.

No break recordings are bundled; load your own loop.

This is independent, unofficial custom firmware, not affiliated with or endorsed by AKAI Professional or inMusic. It is provided without warranty under its component licences. Keep backups before installing.

  • Pad-volume-first kit editing, refined sound controls and User Sound / User Kit saving.
