RHYTHMER OS for MPC Sample is free and open source. This is an early beta for MPC Sample AC50 with stock firmware 1.3.0.12.

Install 0.4.0-beta.3.

Updating from beta.2? Use the full SD ZIP. UPDATE.zip only replaces the app. It does not include the plug-in and catalogue changes in this release.

  1. Save your music. Power off the Sample, remove the SD card and back up the entire card, including projects, samples, presets and the existing autorun folder.
  2. Check the device is MPC Sample AC50 running stock firmware 1.3.0.12. This release is not an FM-1 installer.
  3. Download the full SD ZIP and its SHA-256 file. On macOS, run shasum -a 256 RHYTHMER-OS-0.4.0-beta.3-SD.zip and compare the result.
  4. Extract the ZIP. Copy its contents to the card root, keeping autorun/, Rhythmer/ and Samples/ at the top level. Update the supplied app and plug-in files; preserve your own projects, presets and recordings.
  5. Eject the card safely, insert it and start the Sample. Follow the SD launcher. Check the version is 0.4.0-beta.3 before opening a copy of an existing project.
SD card/

Keep a way back.

To return to the stock app, power off, remove the card and move autorun/ off the card. To restore an earlier RHYTHMER beta, restore its matching app and plug-in backup together. Keep new-format projects as copies.

Hardware controls, audio performance and install/recovery behavior are still pending owner testing. No break recordings are bundled; load your own loop.
