JR EMUL / FAQ

A few useful answers.

What is the difference from JR FX?

JR EMUL focuses on two independent character slots and an output rack. JR FX puts sampler emulation into a broader performance-effects workflow with categories, XY pads and bus routing.

What does 303VS mean?

Vinyl Simulation. It is JR’s original compression, texture and pitch-motion mode, derived from the PATINA direction.

Do the examples use hardware recordings?

The listening examples process the same prepared Amen Break loop through the software models. Every render uses the same input gain; output levels are not normalized, so the model’s gain change remains audible. The spectral plots show the same Amen source; the sweep and soft-clip sine tests are separate diagnostics. No hardware recording is used as a model output.

How close are the models to the original machines?

Published architecture, circuit families and response references guide the models. Software response and stability are checked; exact matching to a specific physical unit has not been certified. Some converter and nonlinear details remain approximations.

Why does the S950 graph rise in the high frequencies?

The main comparison measures the complete record/playback model, including recording emphasis. Playback-only response is a separate curve. The S950 section explains that distinction.

Can I use two processors together?

Yes. Serial processes A then B. A/B switch selects between independent paths. Each slot retains its own model and settings.

Does INPUT need PLAY?

Selecting INPUT enables live processing. PLAY is used for standalone file or demo playback. In an AUv3 host, the host owns input routing and transport.

Can I buy the app now?

JR EMUL is in development. Public release details will be announced through Studio Notes. No release date or price is promised on this page.
