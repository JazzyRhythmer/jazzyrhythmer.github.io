RHYTHMER-specific documentation adaptation, first-pattern tutorial, interface changes and integration instructions: jazzy rhythmer, 2026. Documentation licence: AGPL-3.0-only; see LICENSE.txt. Original source attribution is retained. The original guide's common workflow was checked against the pinned foundation; The 0.4 foundation uses Melodee 0.2.0; RHYTHMER-specific controls are checked against the integrated interface.

Changes include the 36-kit catalogue, single-sound / kit distinction, functional pages and row selection, four-track groups and MIDI-only generation, dedicated Acid settings/seed behavior, user-loop preparation, six-page Break performance and recorded commands, and project/preset scope. Common procedures are rewritten for this interface rather than copied as a replacement for upstream's current guide.

Screens are generated by the RHYTHMER production UI from inspected development fixtures. They are examples rather than hardware photos or proof of device behavior. Asset hashes are in screen-provenance.json. Engine previews reuse the product page's latest production UI atlases. Twenty engine examples and four contextual examples have pause/play controls, render only while visible, and respect Reduce Motion. Control-reference screenshots remain static. Motion is symbolic; audio RMS and inferred held activity drive the demo fixtures, with a reference pitch rather than exact MIDI replay. Code, preset data, recordings, fonts and hardware marks retain their individual notices; documentation adaptation does not relicense those assets.

The static HTML, manual.css and manual.js are the readable page source; no build tool is required to serve this directory. All original rights and authorship remain with their creators. No manufacturer or upstream endorsement is implied.
