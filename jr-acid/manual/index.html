Your first acid line

Start the clock

In standalone, choose INTERNAL and press PLAY. In an AUv3 host, use the host transport. Host audio/MIDI routing is set in the host; JR ACID is an instrument, not an audio effect.

Generate an idea

On PATTERN → GENERATOR, choose root, scale and density. GENERATE creates a new phrase. MUTATE changes unlocked material according to the recipe; a low mutation amount can leave a phrase unchanged.

Preserve the good part

Use step LOCK and PITCH / RHYTHM / ACC / SLIDE LOCK to constrain generation. Locks affect GENERATE/MUTATE; manual edits and full-patch operations remain editable. NEXT LOOP queues a change to the next complete pattern, while NEXT STEP uses the next step boundary.

Notes, steps and keys

Length and pages

LENGTH supports 1–64 steps. Page keys navigate the line and FOLLOW tracks playback. DUPLICATE doubles length up to64. REVERSE, SHUFFLE, ROTATE and COPY/PASTE reshape the phrase.

Edit the piano roll

MOVE selects and drags notes; DRAW paints them; ERASE removes them. Accent, slide and lock lanes edit their own flags. Drag a note beyond the visible pitch region to expand the displayed range.

Record with the keys

KEYS / EXPAND KEYS opens the keyboard dock. Choose two or three octaves, transpose with OCT−/+, and use ACCENT, STEP REC and REST. COLLAPSE returns to the compact keys. Changing layout or closing the editor releases held screen notes.

Recover an edit

UNDO/REDO restore editing history. PANIC releases notes and clears effect tails; in standalone it also stops the internal clock.

Sound and performance

Six main controls

The performance knobs remain accessible while you work. SYNTH exposes oscillator and drive settings, tuning, gain, tempo, swing, glide, filter LFO and distortion high-pass filtering.

Filter voices

The 303 / LADDER 24 control beside CUTOFF selects the diode-style voice or the transistor ladder model. It is a sound choice, not a skin. Filter changes crossfade and are stored with sound/project state.

Modulation

MOD exposes the modulation sources. Set the source, destination and depth, then listen to the result. Tempo-linked controls follow the selected clock. Keep output gain conservative while auditioning unfamiliar patches.

FX RACK

Choose a module

FX RACK offers delay, reverb, compression, phaser, Color, Pump and output/limiter controls. Select a module, then use ACTIVE/BYPASSED. Double-click a knob to reset it.

Delay timing

Choose digital, tape or ping-pong delay. SYNC follows the active host/internal/MIDI clock; FREE uses time in milliseconds. Feedback can extend beyond the note pattern.

DUCK and output

Use the sequenced Pump/DUCK controls for rhythmic level movement. Output low-cut, trim and peak guarding shape the final result. Compression and limiting affect level; compare at a comfortable monitoring volume.

Presets and projects

Choose what loads

PRESETS provides sound/pattern library browsing, bank search and SOUND ONLY / PATTERN ONLY / BOTH. A full patch can replace both sound and pattern, so choose the load scope before auditioning.

Store and save

STORE updates the selected slot. Named project SAVE AS NEW creates a separate file. Portable SAVE SESSION / LOAD SESSION uses .jracid files. MIDI export includes the patch-related data supported by JR ACID; audio rendering and MIDI files serve different purposes.

Checkpoint and recovery

Opening a project first creates a recovery checkpoint. CHECKPOINT/RECOVER is an explicit fallback, not a promise of continuous crash-safe autosave. Back up important session files and exports.

MIDI and AUv3

Notes or clock

Select the port/channel and choose NOTES, CLOCK/TRANSPORT or NOTES + CLOCK. CLASSIC MONO / 303 suits velocity and overlapping-note synths; GENERIC / CC + PROGRAM exposes configurable CC and bank/program control. Set local sound off when using only external gear.

Clock and thru

THRU starts off. MIDI CLOCK IN follows an external master, including transport Continue behavior. Avoid routing a clock back into itself. Refreshing ports should not replace an established connection.

Use in a host

Load JR ACID as an AUv3 instrument and route MIDI and audio in the host. The host supplies tempo, beat position and playback. Incoming MIDI can still play the synth when host transport is stopped. Save the host project to retain state.

Skins, support and credits

Choose your skin

Tap SKIN in the top bar. Modern BK is the default; your saved choice stays selected. Appearance only — your sound and controls stay the same.

The included looks

Modern BK: Black panel. Lime accents. Modern: Graphite hardware with smooth type. Modern Light: Light grey with a soft metal feel. Modern Yellow: A warm yellow hardware panel. Modern Red: Deep red with lime highlights. Modern Purple: Muted purple with lime highlights. JR: Ivory pixels and a green LCD. JR 303: Vintage ivory pixels. Amber LCD.
