## RHYTHMER OS for MPC Sample

**Your MPC Sample. A wider world of sound and groove.**

[Explore the preview](https://jazzyrhythmer.github.io/mpc-sample/) · [Manual](https://jazzyrhythmer.github.io/mpc-sample/manual/) · [First pattern](https://jazzyrhythmer.github.io/mpc-sample/manual/quickstart.html) · [Email updates](https://jazzy-rhythmer.kit.com/6dd4006c7c)

![RHYTHMER OS for MPC Sample startup](mpc-sample/assets/boot/startup.gif?v=miniatures1)

A groovebox environment based on Melodee by Kerem Kiliç (Ellic Studio), with additional engine ports and RHYTHMER tools by Jazzy Rhythmer. This repository hosts the website and manual preview. The OS installer and engine-source release are being prepared separately.
