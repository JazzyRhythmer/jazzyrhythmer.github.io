RHYTHMER ENGINES — original 3D animation previews

These vector frames were produced by the same LiveArt adapter and original
performance_art renderer used in the Mac instrument. Demo WAV envelopes drive
movement. The website plays recorded frames; it does not execute synth DSP.
The artwork retains its original filled faces and wire outlines.

Rhythmer integration and artwork: Jazzy Rhythmer.
Renderer and adapter source: AGPL-3.0-only; original notices retained.
Shared firmware source and credits:
https://github.com/jazzyrhythmer/mpc-sample-rhythmer-os

Audio: thirteen previews reuse the MPC Sample site assets. Seven use the current
Mac preset bank, with the existing preset parameters unchanged. The selected
preset is named beside the sound player. Each file records its source in demos.json.
